# Recipe: belief-statement (8 s)
**Use for:** awareness / educate. One sentence the brand already holds (see `brand.yaml: messages.beliefs`), built visually. **Workflow:** motion-graphics.

| Time | Beat | Notes |
|---|---|---|
| 0-0.8 | signature visual starts building (e.g. isometric blocks rising, or a brand-specific diagram) | motion in the first 0.5 s |
| 0.7 | first half of the statement (text colour, ~96 px) | `pop` |
| 4.0 | second half lands in **accent**, falling in from above | `slam` + camera punch |
| 5.6 | URL / handle | `chime`, hold to the end |

Rule: the statement must be a belief from the brand's own materials. Do not paraphrase it into a new claim.
