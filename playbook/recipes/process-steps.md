# Recipe: process-steps (10 s)
**Use for:** educate / promote. Hook -> numbered steps light up one by one -> CTA. **Workflow:** motion-graphics or general-video.

| Time | Beat | Notes |
|---|---|---|
| 0.1-1.8 | hook, one slam | |
| 1.7-7.0 | 3-4 steps, ~1.2 s each: number circle + label; the active step in accent and larger; connector fills toward the next | `tick` per step, `chime` at the end |
| 7.2-10 | CTA with URL | |

Use the brand's own process (`brand.yaml: messages.process`) when it has one; keep labels to 1-2 words.
