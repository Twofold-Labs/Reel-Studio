# Recipe: proof-stat (8 s)
**Use for:** social proof. Hook -> a real number counts up -> CTA. **Workflow:** motion-graphics (its stat/count-up pattern).

| Time | Beat | Notes |
|---|---|---|
| 0.1-2.4 | hook (2 slams: setup, tension in accent) | `slam` x2 |
| 2.3-6.3 | number counts up inside a progress ring; label + one-line source/context under it | `tick`s while counting, `chime` on the final value |
| 6.3-8 | CTA | |

**Only a real figure the user/brand supplied, with its context/source. Never invent, round up or imply a statistic.** Seek-safe counting: pre-build N number elements and switch them with `set`/opacity at fixed times (no `onUpdate`).
